## Publish with GitHub Pages

1. Create a public GitHub repository, for example `new-bot-site`.
2. Upload all files from this folder to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
5. Save and wait for GitHub Pages to publish.

Your links will look like:
- https://YOUR-USERNAME.github.io/new-bot-site/
- https://YOUR-USERNAME.github.io/new-bot-site/privacy.html
- https://YOUR-USERNAME.github.io/new-bot-site/terms.html
- https://YOUR-USERNAME.github.io/new-bot-site/data-deletion.html

Use the privacy.html URL in Meta's Privacy Policy URL field.
Use the data-deletion.html URL where Meta requests data deletion instructions.
