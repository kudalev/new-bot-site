new_bot

An automation tool that detects predefined keywords in Instagram comments and sends the requested resource to the user through Instagram Direct.

Privacy Policy Terms of Service Data Deletion

How it works

  • A user leaves a public comment containing a predefined keyword.
  • The application receives the comment event through the official Instagram API.
  • The application sends an automated private reply with the requested link or material.
The application does not request Instagram passwords and does not sell personal information.
